# MNIST Digit Classification

This project implements a neural network model to classify handwritten digits from the [MNIST dataset](http://yann.lecun.com/exdb/mnist/).  
It is built using **TensorFlow**, with support from **NumPy** and **Matplotlib** for numerical operations and visualization.

---

## Features

- Loads the MNIST dataset of handwritten digits (0–9).
- Preprocesses the images (normalization, reshaping).
- Builds and trains a neural network using TensorFlow/Keras.
- Evaluates the model on the test dataset.
- Visualizes training progress and predictions.

---

## Results

The model typically achieves ~98% accuracy on the MNIST test set.
