# ASL Alphabet Classification with Convolutional Neural Networks

This project enhances ASL (American Sign Language) alphabet recognition by implementing a Convolutional Neural Network (CNN) using PyTorch. It builds on image classification techniques to achieve improved accuracy in classifying hand gesture images representing alphabet letters.

## Key Features

- Utilizes ASL image datasets for multi-class classification
- Implements a CNN architecture with `nn.Conv2d` layers in PyTorch
- Handles data loading and transformation using `ImageFolder` and `DataLoader`
- Trains and evaluates the model using standard PyTorch training loops
- Visualizes training performance and predictions

## Requirements

- Python
- PyTorch
- Torchvision
- Matplotlib

## Objective

To train a CNN that accurately classifies American Sign Language alphabet signs from images, demonstrating the effectiveness of convolutional layers in image recognition tasks.
