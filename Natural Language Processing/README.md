# Introduction to NLP with PyTorch

This project explores the fundamentals of Natural Language Processing (NLP) using PyTorch. It walks through text preprocessing, vocabulary creation, and training simple models for text-based tasks.

## Key Features

- Demonstrates text processing and vocabulary building
- Applies tokenization and numerical encoding techniques
- Trains a basic model on textual input data using PyTorch
- Focuses on foundational concepts rather than complex architectures

## Requirements

- Python
- PyTorch
- Basic NLP libraries (e.g., re, collections)

## Objective

To introduce the core steps involved in building an NLP pipeline, from text preprocessing to model training, using PyTorch as the backend framework.
