# MNIST Digit Classification with PyTorch

This project demonstrates handwritten digit classification using the MNIST dataset. A neural network is implemented and trained using PyTorch, showcasing the essential steps in building, training, and evaluating a deep learning model.

## Key Features

- Uses the MNIST dataset of handwritten digits
- Implements a custom neural network with `nn.Module`
- Applies data preprocessing and augmentation using `torchvision.transforms`
- Trains the model using `torch.optim.Adam` and evaluates its accuracy
- Visualizes sample predictions using matplotlib

## Requirements

- Python
- PyTorch
- Torchvision
- Matplotlib

## Objective

To provide a foundational understanding of training neural networks using PyTorch on image data.
