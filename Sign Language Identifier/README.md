# American Sign Language (ASL) Alphabet Classification

This project focuses on classifying American Sign Language (ASL) alphabet signs using deep learning. A custom convolutional neural network is trained on image data to recognize and classify hand gestures representing ASL letters.

## Key Features

- Uses image datasets of ASL hand signs
- Implements a custom CNN using PyTorch and `nn.Module`
- Loads and processes data using `torchvision.datasets.ImageFolder` and `DataLoader`
- Trains and evaluates the model for multi-class classification
- Includes basic data visualization and model performance insights

## Requirements

- Python
- PyTorch
- Torchvision
- Matplotlib

## Objective

To develop a deep learning model that can accurately classify images of ASL alphabet signs using computer vision and PyTorch.
