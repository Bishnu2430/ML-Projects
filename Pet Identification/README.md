# Doggy Door Classifier

This project aims to develop and deploy a binary image classification model that determines whether a given image contains a dog, enabling the simulation of an AI-powered doggy door.

## Part 1: Doggy Door (Training)

- Implements a CNN-based image classifier using PyTorch and torchvision
- Trains the model on a labeled dataset for binary classification (e.g., dog vs. not-dog)
- Uses data transformations and standard training loops to build the model

## Part 2: Presidential Doggy Door (Inference)

- Loads the trained model and performs inference on new images
- Processes input images and displays predictions
- Simulates a real-time decision-making system for dog detection

## Requirements

- Python
- PyTorch
- Torchvision
- PIL (Python Imaging Library)
- Matplotlib

## Objective

To build and deploy a deep learning model that can automatically detect the presence of a dog in an image, simulating a smart doggy door that opens only for dogs.
